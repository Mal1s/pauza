# Бот команды «ПАУЗА»

Telegram-бот принимает анкеты игроков в личных сообщениях, хранит их в SQLite и отправляет карточки в закрытую группу тренеров.

## Настройка

1. Создай бота у [@BotFather](https://t.me/BotFather).
2. Добавь бота в закрытую группу тренеров. Для редактирования карточек выдай ему право удалять и редактировать сообщения; для надёжной работы с анкетами в группе отключи Privacy Mode у BotFather.
3. В Replit открой **Tools → Secrets** и добавь:
   - `BOT_TOKEN` — токен от BotFather;
   - `ADMIN_CHAT_ID` — числовой ID группы, обычно начинается с `-100`.
4. Запусти workflow **ПАУЗА Telegram Bot**.

Для разработки из корня проекта:

```bash
python3.11 -m pauza_bot.main
```

SQLite-файл `pauza_bot/pauza.db` создаётся автоматически. Путь можно переопределить переменной `PAUZA_DB_PATH`. Данные игроков не включаются в Git.

## Что умеет бот

- Анкета из 16 этапов, прогресс, проверка ответов, возврат назад, пропуск необязательных вопросов и экран редактирования.
- Одно обновляемое сообщение в личном чате; ответы игрока удаляются после обработки.
- Статусы заявок и уведомления игроку о приглашении или отказе.
- Кнопки тренеров для связи, отказа, резерва, заметок и назначения просмотра.
- Команды закрытой группы: `/stats`, `/new`, `/find имя`, `/export` (CSV с BOM для Excel).
- Ограничение повторной анкеты активной заявкой и 14-дневная пауза после отказа.

## Запуск 24/7

Workflow работает, пока запущен. Для постоянной работы настрой deployment типа **Reserved VM** или **Background Worker** с командой `python3.11 -m pauza_bot.main` и добавь те же Secrets в среду deployment. Не используй autoscale/web-server режим для long polling: процесс бота должен оставаться запущенным, а файл SQLite — на постоянном диске.

FSM текущей анкеты хранится в памяти процесса. Если бот перезапустится посреди заполнения, игроку нужно будет начать анкету заново; уже отправленные анкеты и заметки сохраняются в SQLite.
